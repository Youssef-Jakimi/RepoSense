# Bob Task Session Reports

This folder contains all Bob IDE task session reports for hackathon judging purposes.

## Contents

This folder should include:
- **Screenshots**: Task session consumption summary screenshots for each relevant task
- **Markdown files**: Exported task history markdown files from Bob IDE

## How to Export Sessions

1. Open Bob IDE's chat interface
2. Click **Views and More Actions** → **History**
3. Confirm you're in the correct project workspace (or select "All")
4. For each task related to your project:
   - Select the task from history
   - Click the task header to view consumption summary
   - Take a screenshot of the consumption summary
   - Click Export task history icon to download as markdown
   - Save both files to this folder

## Security Note

⚠️ **IMPORTANT**: Ensure all credentials and API keys are removed from your code before exporting and uploading to this public repository. IBM Security will deactivate accounts if credentials are detected.
